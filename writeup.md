# Assignment Write-Up

1. The hardest part was building the crossword without JavaScript and still making it easy to use. HTML and CSS were okay for layout and styling, but making the grid interactive with only inputs, labels, and CSS selectors took more time than a normal static page.

2. I built the puzzle grid with CSS Grid and used a separate `input maxlength="1"` in each open square so the user can type directly into the board. I also added clue numbers with CSS and used a checkbox to show the solution. I thought about using a table, but CSS Grid made the board easier to control and responsive.

3. When designing the site, I focused on readability, simple navigation, and making sure the crossword was the main part of the site. I kept the colors simple and the layout clean so the puzzle was easy to use. I am most proud of making the crossword work without JavaScript and still keeping it keyboard-friendly and mobile-friendly.

4. Given more time, I would make the crossword better, add more clue feedback, and make the puzzle bigger or more personal. I would also spend more time on the design and maybe add more pages.

5. I spent about 4.6 hours on this assignment.

6. One assumption I made was that the crossword could be small and simple as long as it met the requirements and worked on both desktop and mobile.

7. I used the crossword at https://minicrossword.us.com/ as a reference for the puzzle idea and layout, and I changed the puzzle content for this project. I also used AI help to draft some of the site text and puzzle wording. I did not import any font or icon libraries.
